**OpenClaw** is the agent runtime that powers Brain and every ClawBot. It's open, file-based, and configurable.

## What it gives you

- **Plain-file configs** — `IDENTITY.md`, `SOUL.md`, `AGENTS.md`, `TOOLS.md`, `USER.md`. Edit them like any other text file.
- **Memory layers** — working notes, structured event logs, and a search index. Agents read and write all three.
- **Skills** — drop-in capabilities (e.g. `configure-agent` for spawning new bots).
- **Tools** — connectors and actions an agent can invoke.

## Why it matters to you

You can see exactly what your agent believes, what tools it has, and what it remembers. Nothing is hidden in a vendor's prompt. If something is off, you open the file and fix it.

## The three memory layers

1. **Working memory** — markdown notes the agent maintains itself
2. **Logs** — append-only records of decisions and activity
3. **Search index** — auto-built from layer 1, used to retrieve context during a session

You don't manage the index. You read and edit layer 1. Layer 2 is the historical truth.
