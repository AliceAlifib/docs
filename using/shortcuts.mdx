---
title: "Keyboard shortcuts"
description: "The keys worth learning."
---

Press `?` in the app at any time for the live list.

| Key | Action |
|---|---|
| `?` | Show or hide the shortcuts overlay |
| `/` or `Ctrl`/`⌘`+`K` | Find a card or enabler |
| `v` | On the factory, switch Operational and Architecture |
| `n` | New card when an enabler is open. Otherwise, [Needs you](/using/needs-you) |
| `r` | Reset the view. The map returns home. The factory recentres |
| `f` | Full screen |
| `Esc` | Close the topmost panel. In full screen the browser takes Esc |
| `` ` `` or `q` | Close the topmost panel, including in full screen |
| `←` `→` | Previous or next item while reviewing |
| `Ctrl` or `⌘` `C` | Copy the open name with its id |

**One `Esc`, one action.** Panels close one at a time, topmost first, rather than all at once.

Single-letter shortcuts are suppressed while you are typing. `Esc` still works while typing, so you can dismiss a panel mid-edit — except inside an inline rename, where it cancels the rename instead.
