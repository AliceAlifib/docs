# Alice.In Docs

User-facing documentation for [Alice.In](https://alice.in) — the visual project execution engine.

Built with [Mintlify](https://mintlify.com). Pushes to `main` auto-deploy.

## Structure

- `docs.json` — site config (nav, branding, theme)
- `index.mdx` — landing page
- `quickstart.mdx` — onboarding
- `concepts/` — Project Brain, ClawBots, Sprites, OpenClaw
- `guides/` — Commands, Tones, Memory
- `logo/` — brand assets

## Local preview

```
npm i -g mint
mint dev
```

Opens at `http://localhost:3000`.
