---
title: "Keyboard shortcuts"
description: "The keys worth learning."
---

Press `?` in the app at any time for the live list.

| Key | Action |
|---|---|
| `?` | Show or hide the shortcuts overlay |
| `v` | Switch view — operational ⇄ architecture |
| `r` | Reset the view — map back to home, factory re-centres the camera |
| `n` | New card when an enabler panel is open; otherwise [Needs you](/using/needs-you) |
| `a` | Artifacts |
| `f` | Full screen |
| `Shift` + `F` | Immersive mode — hides the edge chrome, keeps the browser's own |
| `e` | Grow or shrink the panel you are in |
| `Esc` | Close the topmost panel |
| `` ` `` or `q` | Close the topmost panel — use these in full screen, where the browser owns `Esc` |
| `←` `→` | Previous / next item when reviewing |
| `Space` (hold) | Push to talk in chat |
| `Ctrl` / `⌘` + `D` | Dictation on or off in chat |
| `Enter` | Send a chat message |

Two rules worth knowing:

- **`e` resizes, `Esc` closes.** Expanding a panel never means pressing `Esc` twice.
- **One `Esc`, one action.** Panels close one at a time, topmost first, rather than all at once.

Single-letter shortcuts are suppressed while you are typing. `Esc` still works while typing, so you can dismiss a panel mid-edit — except inside an inline rename, where it cancels the rename instead.
