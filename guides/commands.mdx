---
title: "Commands"
description: "Slash commands for switching models, tones, and skills."
---

Type these directly in your session with Brain (or any ClawBot).

## Model

Switch reasoning depth on demand.

| Command | Effect |
|---|---|
| `/model flash` | Gemini 3 Flash Preview — fast, default |
| `/model pro` | Gemini 3 Pro Preview — deeper reasoning |

## Tone

Change how she talks.

| Command | Effect |
|---|---|
| `/set-tone` | Show available tone packages |
| `/set-tone direct` | Blunt, fast, no filler |
| `/set-tone energized` | High-energy co-founder mode |
| `/set-tone coach` | Steady, encouraging |

## Skills

Trigger a packaged capability.

| Command | Effect |
|---|---|
| `/configure-agent` | Interview + generate configs for a new ClawBot |

## Session

Built-in OpenClaw controls.

| Command | Effect |
|---|---|
| `/status` | Session status — model, tokens, cost |
| `/new` or `/reset` | Reset the session |
| `/compact` | Compact session context |
| `/verbose on\|off` | Toggle verbose mode |
| `/usage off\|tokens\|full` | Per-response usage footer |
